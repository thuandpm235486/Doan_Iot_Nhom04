# ĐỒ ÁN INTERNET OF THINGS (IoT)

## ĐỀ TÀI: MÔ PHỎNG HỆ THỐNG GIÁM SÁT VÀ CẢNH BÁO RÒ RỈ KHÍ LPG

Hệ thống sử dụng ESP32, mô hình cảm biến MQ-2 trên Wokwi và Adafruit IO, chọn propane làm khí tham chiếu. Gồm 4 trạm và dashboard, hỗ trợ giám sát nồng độ, cảnh báo, điều khiển van, xác nhận kiểm tra và khởi động lại từ xa.
